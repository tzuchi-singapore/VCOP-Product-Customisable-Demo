# VCOP Product Studio — live 3D product demo

Interactive 3D showcase of two VCOP designs, built from the original blueprints:

- **BLOCKS Smart Lockset — Demo Kit** (4 lockers + 1 tech compartment, 600 × 450 × 468 mm): RFID, Face ID and PIN unlock with working bolt / 'C' hook / hinge mechanics, removable compact-laminate lid, raisable PCB tray, handle and hinge options.
- **BNP Paribas Trader Desk** (1500 × 950 module): height controller driving 3-stage lifting columns (680–1250 mm), cable spines, perforated cabinet doors, CPU tray slide, 4/6/8 live trading screens, back-to-back pair.

Features: exploded view with labelled components, finish configurator (HPL, FENIX NTM, woodgrain, Polykem, RAL powder-coat, metal finishes), free 360° orbit, original blueprints (image + PDF), Higgsfield photoreal renders.

Live: https://tzuchi-singapore.github.io/VCOP-Blocks-smart-lock-set-Demo/

Static site, no build step — `index.html` + `vendor/` (three.js r160) + `assets/` + `blueprints/`.
